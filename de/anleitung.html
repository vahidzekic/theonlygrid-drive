Anleitung

So installieren Sie TOG Drive, erstellen ein Konto und nutzen es sicher. Die App gibt es auf Deutsch, Englisch und Serbisch; die Sprache wählen Sie im Menü mit der Flagge oben rechts. Version 0.1.0 ist noch nur auf Serbisch, die deutschen Bezeichnungen unten gelten ab der nächsten Version.

Alpha. TOG Drive läuft in einem Testnetz. Daten können gelöscht werden, wenn das Testnetz neu gestartet wird. Bewahren Sie nicht die einzige Kopie wichtiger Dateien darin auf.

1. Installation

Öffnen Sie die neueste Version und laden Sie unter Assets die Datei für Ihr System herunter: …-windows-x64.zip, …-linux-x64.tar.gz oder die macOS-Datei (.zip, nach der Notarisierung eine .dmg). Fehlt für Ihr System noch eine Datei in der neuesten Version, kommt sie mit einer späteren. Jede Version enthält eine Datei SHA256SUMS zur Prüfung der Downloads.

Windows

Klicken Sie mit der rechten Maustaste auf tog-drive-…-windows-x64.zip → Alle extrahieren und starten Sie dann tog_drive.exe. Die App ist noch nicht signiert, daher zeigt Microsoft Defender SmartScreen möglicherweise „Der Computer wurde durch Windows geschützt“: Klicken Sie auf Weitere Informationen und dann auf Trotzdem ausführen. Laden Sie die App nur von unserer Release-Seite auf GitHub herunter.

macOS

Doppelklicken Sie auf den Download, um ihn zu entpacken (.zip) oder zu öffnen (.dmg), und ziehen Sie TOG Drive in den Ordner Programme. Solange die App nicht von Apple notarisiert ist, blockiert Gatekeeper das erste Öffnen. Unter macOS 14 und älter klicken Sie bei gedrückter Ctrl-Taste auf die App, wählen Öffnen und dann erneut Öffnen. Unter macOS 15 und neuer schließen Sie die Warnung, öffnen Systemeinstellungen → Datenschutz & Sicherheit und klicken auf Dennoch öffnen. Nach einem Update fragt macOS eventuell erneut, ob TOG Drive seine Schlüsselbundeinträge verwenden darf: Wählen Sie Immer erlauben. Voraussetzung ist macOS 12 oder neuer.

Linux

Ein x64-Archiv .tar.gz für Systeme mit GTK 3 und glibc 2.34+ (Ubuntu 22.04/24.04, Debian 12, aktuelles Fedora). Die Bibliothek für das Symbol in der Taskleiste ist nötig, sonst startet die App nicht:

# Ubuntu, Debian
sudo apt install libayatana-appindicator3-1
# Fedora
sudo dnf install libayatana-appindicator-gtk3

tar xzf tog-drive-*-linux-x64.tar.gz
cd tog-drive-*-linux-x64
./tog_drive        # aus dem Ordner starten, oder:
./install.sh       # Installation für den Benutzer mit Menüeintrag, ohne sudo

Schlüssel landen im Schlüsselbund des Systems (GNOME Keyring, KWallet), falls vorhanden, sonst in einer Datei, die nur Sie lesen können.

2. Neues Konto

  1. Wählen Sie Neues Konto.
  2. Wählen Sie einen Benutzernamen: 3 bis 32 Zeichen, Kleinbuchstaben a–z, Ziffern und . _ -. Andere verwenden ihn, um mit Ihnen zu teilen.
  3. Wählen Sie ein Passwort mit mindestens 10 Zeichen.
  4. Geben Sie Ihren Einladungscode ein. Dazu erhalten Sie die Serveradresse; tragen Sie sie unter Erweitert: Server ein. Bleibt das Feld leer, arbeitet die App nur lokal auf diesem Computer.
  5. Schreiben Sie die Wiederherstellungsphrase aus 24 Wörtern auf, bestätigen Sie die Warnung und tippen Sie die Wörter ein, nach denen die App fragt. Erst dann wird das Konto auf dem Server angelegt.

3. Wiederherstellungsphrase

Die Phrase ist der Hauptschlüssel Ihres Kontos in einer Form, die Sie aufschreiben können. Sie entsteht auf Ihrem Gerät, und wir sehen sie nie.

  • Sie stellt den Zugang wieder her, wenn Sie Ihr Passwort vergessen. Ein Zurücksetzen per E-Mail gibt es nicht: Wir haben Ihre Schlüssel nicht.
  • Verlieren Sie Passwort und Phrase und ist kein Gerät mehr angemeldet, sind Ihre Dateien für immer verloren.
  • Wer die Phrase hat, kann Ihre Dateien öffnen. Geben Sie sie niemals weiter; wir werden nie danach fragen.
  • Schreiben Sie sie der Reihe nach und nummeriert auf Papier und bewahren Sie sie sicher auf. Fotografieren Sie sie nicht, versenden Sie sie nicht per Nachricht und legen Sie sie nicht in dasselbe TOG Drive. Ein Passwort-Manager, dem Sie vertrauen, eignet sich für eine zweite Kopie.

4. Anmeldung auf einem weiteren Gerät

Installieren Sie die App, wählen Sie Anmelden, geben Sie Benutzernamen, Passwort und dieselbe Serveradresse ein und geben Sie dem Gerät einen Namen, an dem Sie es später erkennen.

5. Meine Ablage

Meine Ablage zeigt Ihre Dateien; Geteilt zeigt Ordner, die Sie teilen, und Ordner, die mit Ihnen geteilt werden. Verwenden Sie Hochladen und Neuer Ordner. Mit einem Rechtsklick auf ein Element können Sie es herunterladen, umbenennen, verschieben, teilen, einen Link erstellen, Versionen oder Zugriffsrechte ansehen oder es in den Papierkorb verschieben. Laden Sie eine Datei mit demselben Namen in denselben Ordner hoch, wird sie zu einer neuen Version. Die Seite Konto zeigt den belegten Speicher; das Testkontingent beträgt 10 GB, Papierkorb und Versionen zählen mit.

6. Synchronisierter Ordner (Desktop)

Wählen Sie unter Synchronisierung einen Ordner (am besten leer, auf einem lokalen Laufwerk) und drücken Sie Starten. Änderungen gehen innerhalb von Sekunden in beide Richtungen; Jetzt synchronisieren synchronisiert sofort. Wurde eine Datei an zwei Stellen geändert, geht nichts verloren: Daneben erscheint eine Konfliktkopie mit Gerätenamen und Datum. Namen, die manche Systeme nicht speichern können (etwa a:b oder CON), Verknüpfungen und Sonderdateien werden übersprungen und aufgelistet. Ein Ordner kann jeweils nur von einer App synchronisiert werden. Netzlaufwerke (NFS, SMB) bemerken Änderungen anderer erst spät; verwenden Sie ein lokales Laufwerk. Die Synchronisierung läuft, solange die App läuft.

7. Teilen mit anderen Konten

  1. Rechtsklick auf einen Ordner → Teilen. Vorerst lassen sich nur Ordner teilen; für eine einzelne Datei teilen Sie ihren Ordner oder erstellen einen Link.
  2. Geben Sie den Benutzernamen des Empfängers ein, drücken Sie Suchen und wählen Sie Lesen oder Lesen und Schreiben.
  3. Vergleichen Sie den Schlüssel-Fingerabdruck (8 Gruppen zu je 5 Ziffern) mit der Person über einen anderen Weg. Sie sieht ihren auf der Seite „Konto“.
  4. Stimmt er überein, haken Sie Ich habe den Fingerabdruck mit der Person verglichen an und bestätigen Sie. Weicht er ab, teilen Sie nicht.

Die App merkt sich den Fingerabdruck und warnt Sie, wenn er sich ändert. Beenden Sie eine Freigabe, entzieht der Server den Zugriff sofort; was die Person bereits heruntergeladen hat, bleibt bei ihr. Dateien, die ein Mitglied hinzufügt, zählen zum Kontingent des Eigentümers, und ein Mitglied kann nichts endgültig löschen.

8. Öffentliche Links

Rechtsklick → Link erstellen. Legen Sie optional ein Passwort, eine Gültigkeit in Tagen und eine maximale Zahl an Downloads fest und kopieren Sie dann den Link. Der Schlüssel zum Entschlüsseln ist der Teil nach #, der nie an den Server gesendet wird; daher kann jeder mit dem Link ihn öffnen. Senden Sie ein Passwort über einen anderen Weg. Unter Links sehen Sie Ihre Links mit Download-Zahl und Ablaufdatum; die vollständige Adresse erscheint nur auf dem Gerät, das den Link erstellt hat. Ein gelöschter Link ist sofort deaktiviert. Der Server kann Links für neue kostenlose Konten einschränken (zum Beispiel bis das Konto 30 Tage alt ist). In der Alpha öffnen Empfänger Links mit dem Kommandozeilenwerkzeug von TOG Drive; das Öffnen im Browser ist geplant.

9. Papierkorb und Versionen

Gelöschte Elemente bleiben 30 Tage im Papierkorb und werden dann endgültig entfernt. Wiederherstellen holt sie zurück, Endgültig löschen entfernt sie für immer. Danach sind die Schlüssel der Datei vernichtet, sodass verschlüsselte Daten, die noch im Netzwerk liegen, nicht mehr lesbar sind. Versionen listet frühere Versionen mit Datum, Größe und Gerät; das Wiederherstellen erzeugt eine neue Version und löscht nichts. Ältere Versionen werden 30 Tage aufbewahrt.

10. Geräte und Widerrufen

Konto → Geräte listet jedes Gerät mit Zugriff. Widerrufen Sie ein Gerät, das Sie verloren haben oder nicht kennen; Sie bestätigen mit Ihrem Passwort. Es wird abgemeldet und kann das Konto nicht mehr öffnen oder Dateien ändern; was es bereits heruntergeladen hat, bleibt darauf. Ein Gerät kann sich nicht selbst widerrufen. Hat das widerrufene Gerät Änderungen hinterlassen, die dieses Gerät noch nicht geprüft hat, fragt die App Sie bei jeder, ob Sie sie behalten oder zurücksetzen. Ein widerrufenes Gerät kann sich mit dem Passwort als neues Gerät wieder anmelden.

11. Wiederherstellung mit der Phrase

Wählen Sie Mit Phrase wiederherstellen, geben Sie Ihren Benutzernamen, die 24 Wörter, die Serveradresse und ein neues Passwort ein und drücken Sie Zugang wiederherstellen. Lassen Sie Phrase durch eine neue ersetzen eingeschaltet: Sie schreiben eine neue Phrase auf und bestätigen sie, die alte funktioniert dann nicht mehr. Anschließend zeigt die App Ihren Fingerabdruck und die Geräteliste; vergleichen Sie den Fingerabdruck mit einem gespeicherten und widerrufen Sie jedes Gerät, das Sie nicht kennen.

12. Autostart und Taskleiste

Der Schalter TOG Drive bei der Anmeldung am Computer starten (standardmäßig aus) startet die App im Hintergrund, wenn Sie sich am Computer anmelden. Wenn Sie das Fenster schließen, läuft sie in der Taskleiste (Windows) oder Menüleiste (macOS) weiter, mit TOG Drive öffnen und Beenden. Unter Linux wird das Fenster minimiert, da manche Desktops keine Symbole in der Taskleiste zeigen. Es läuft immer nur eine Instanz.

13. Mobil

Apps für iPhone, iPad und Android sind nach der Desktop-Alpha geplant: dasselbe Konto und Passwort, das Telefon als weiteres Gerät, das Sie widerrufen können, dieselbe Verschlüsselung auf dem Gerät und später Zugriff aus der Dateien-App des Systems sowie eine Fotosicherung. Bis dahin verwenden Sie die Desktop-App.

14. Häufige Fragen

Können Sie meine Dateien sehen?

Nein. Inhalte und Namen werden auf Ihrem Gerät mit Schlüsseln verschlüsselt, die wir nicht haben. Siehe So funktioniert es.

Ich habe mein Passwort vergessen.

Nutzen Sie die Wiederherstellung mit der Phrase. Ohne Passwort, Phrase und angemeldetes Gerät lässt sich der Zugang nicht wiederherstellen.

Kostet es etwas?

Die Alpha ist kostenlos, mit 10 GB für Testdaten. Bezahlte Tarife gibt es noch nicht.

Sind meine Daten dauerhaft?

Im Testnetz nicht: Sie können gelöscht werden, wenn das Netz neu startet. Bewahren Sie Kopien woanders auf.

Brauche ich eine Kryptowährung oder ein Wallet?

Nein. Der Betreiber des Dienstes bezahlt den Speicher im Netzwerk. Sie brauchen nur Benutzernamen und Passwort.

Wie lösche ich mein Konto?

Siehe Konto löschen.
