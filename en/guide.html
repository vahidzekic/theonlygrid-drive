Guide

How to install TOG Drive, create an account and use it safely. The app itself is in Serbian for now; button names are given in Serbian with the English meaning.

Alpha. TOG Drive runs on a test network. Data may be erased when the test network is restarted. Do not keep the only copy of important files in it.

1. Installation

Open the latest release and, under Assets, download the file for your system: …-windows-x64.zip, …-linux-x64.tar.gz, or the macOS file (.zip, a .dmg once notarized). If your system has no file in the latest release yet, it will come in a later one. Each release has a SHA256SUMS file for checking downloads.

Windows

Right-click tog-drive-…-windows-x64.zip → Extract All, then run tog_drive.exe. The app is not signed yet, so Microsoft Defender SmartScreen may show “Windows protected your PC”: click More info, then Run anyway. Only download the app from our GitHub releases page.

macOS

Double-click the download to unpack (.zip) or open (.dmg) it, and drag TOG Drive to Applications. Until the app is notarized by Apple, Gatekeeper blocks the first open. On macOS 14 and earlier, Control-click the app and choose Open, then Open again. On macOS 15 and later, close the warning, go to System Settings → Privacy & Security and click Open Anyway. After an update, macOS may ask again whether TOG Drive may use its Keychain items: choose Always Allow. Requires macOS 12 or later.

Linux

An x64 .tar.gz archive for systems with GTK 3 and glibc 2.34+ (Ubuntu 22.04/24.04, Debian 12, recent Fedora). The tray icon library is required, otherwise the app does not start:

# Ubuntu, Debian
sudo apt install libayatana-appindicator3-1
# Fedora
sudo dnf install libayatana-appindicator-gtk3

tar xzf tog-drive-*-linux-x64.tar.gz
cd tog-drive-*-linux-x64
./tog_drive        # run from the folder, or:
./install.sh       # per-user install with a menu entry, no sudo

Keys go to the system keyring (GNOME Keyring, KWallet) when there is one; otherwise to a file readable only by you.

2. New account

  1. Choose Novi nalog (New account).
  2. Pick a username: 3 to 32 characters, lowercase a–z, digits and . _ -. Others use it to share with you.
  3. Pick a password of at least 10 characters.
  4. Enter your invite code. You get the server address with it; enter it under Napredno: server (Advanced: server). Left empty, the app works only locally on this computer.
  5. Write down the 24-word recovery phrase, confirm the warning, then type the words the app asks for. Only then is the account created on the server.

3. Recovery phrase

The phrase is your account's master key in a form you can write down. It is created on your device and we never see it.

  • It restores access if you forget your password. There is no e-mail password reset: we do not have your keys.
  • If you lose both the password and the phrase and have no signed-in device, your files are gone for good.
  • Anyone with the phrase can open your files. Never share it; we will never ask for it.
  • Write it on paper, in order and numbered, and keep it somewhere safe. Do not photograph it, send it in a message or store it in the same TOG Drive. A password manager you trust is fine for a second copy.

4. Signing in on another device

Install the app, choose Prijava (Sign in), enter your username, password and the same server address, and give the device a name you will recognize later.

5. My drive

Moj disk (My drive) shows your files; Deljeno (Shared) shows folders you share and folders shared with you. Use Otpremi (Upload) and Nova fascikla (New folder). Right-click an item to download, rename, move, share, make a link, see versions or who has access, or move it to the trash. Uploading a file with the same name into the same folder makes it a new version. The Nalog (Account) page shows your storage use; the test quota is 10 GB, and trash and versions count toward it.

6. Sync folder (desktop)

On Sinhronizacija (Sync), pick a folder (preferably empty, on a local disk) and press Pokreni (Start). Changes go both ways within seconds; Sinhronizuj sada syncs immediately. If a file was changed in two places, nothing is lost: a conflict copy with the device name and date appears next to it. Names some systems cannot store (like a:b or CON), links and special files are skipped and listed. One folder can be synced by one app at a time. Network drives (NFS, SMB) see remote changes late; use a local disk. Sync runs while the app runs.

7. Sharing with other accounts

  1. Right-click a folder → Podeli (Share). Only folders are shared for now; for a single file, share its folder or create a link.
  2. Enter the recipient's username, press Pronađi (Find) and choose read or read-and-write.
  3. Compare the key fingerprint (8 groups of 5 digits) with the person through another channel. They see theirs on the Account page.
  4. If it matches, tick Proverio sam otisak sa osobom (I checked the fingerprint) and confirm. If it differs, do not share.

The app remembers the fingerprint and warns you if it changes. Ending a share removes access on the server at once; what the person already downloaded stays with them. Files a member adds count toward the owner's quota, and a member cannot permanently delete anything.

8. Public links

Right-click → Javni link (Public link). Optionally set a password, an expiry in days and a maximum number of downloads, then copy the link. The decryption key is the part after #, which is never sent to the server, so anyone with the link can open it: send a password through a different channel. Linkovi (Links) lists your links with download counts and expiry; the full URL shows only on the device that made it. Deleting a link disables it at once. The server may limit links for new free accounts (for example until the account is 30 days old). In the alpha, recipients open links with the TOG Drive command-line tool; opening in a browser is planned.

9. Trash and versions

Deleted items stay in Kanta (Trash) for 30 days, then are purged. Vrati restores, Obriši zauvek deletes for good. After purging, the file's keys are destroyed, so any encrypted bytes still on the network can no longer be read. Verzije (Versions) lists earlier versions with date, size and device; restoring makes a new version and deletes nothing. Older versions are kept for 30 days.

10. Devices and revoking

Nalog → Uređaji (Account → Devices) lists every device with access. Opozovi (Revoke) a device you lost or do not recognize; you confirm with your password. It is signed out and can no longer open the account or change files; what it already downloaded stays on it. A device cannot revoke itself. If the revoked device left changes this device had not checked, the app asks you to keep each one or roll it back. A revoked device can sign in again with the password as a new device.

11. Recovery with the phrase

Choose Oporavak frazom (Recover with phrase), enter your username, the 24 words, the server address and a new password, and press Vrati pristup. Keep Zameni frazu novom (Replace the phrase) on: you write down and confirm a new phrase, and the old one stops working. The app then shows your fingerprint and device list; compare the fingerprint with one you saved and revoke any device you do not recognize.

12. Startup and tray

The switch Pokreni TOG Drive pri prijavi na računar (Start at login, off by default) starts the app in the background when you sign in to your computer. Closing the window keeps it running in the tray (Windows) or menu bar (macOS), with Otvori TOG Drive (Open) and Izađi (Quit). On Linux the window minimizes, since some desktops show no tray icons. Only one copy runs at a time.

13. Mobile

iPhone, iPad and Android apps are planned after the desktop alpha: the same account and password, a phone as one more device you can revoke, the same on-device encryption, and later access from the system Files app and photo backup. Until then, use the desktop app.

14. FAQ

Can you see my files?

No. Contents and names are encrypted on your device with keys we do not have. See How it works.

I forgot my password.

Use recovery with the phrase. Without the password, the phrase and a signed-in device, access cannot be restored.

Does it cost anything?

The alpha is free, with 10 GB for test data. There are no paid plans yet.

Is my data permanent?

Not on the test network: it may be erased when the network restarts. Keep copies elsewhere.

Do I need cryptocurrency or a wallet?

No. The service operator pays for storage on the network. You only need a username and password.

How do I delete my account?

See Account deletion.
