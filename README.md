# TOG Drive

TOG Drive je skladište fajlova sa end-to-end šifrovanjem na mreži The Only Grid (TOG).
Fajlovi se šifruju na vašem uređaju pre slanja, pa ih ni server ni provajderi skladišta ne mogu pročitati.

- **Sajt i uputstvo:** https://vahidzekic.github.io/theonlygrid-drive/
- **Preuzimanje (Windows, macOS, Linux):** [Releases](https://github.com/vahidzekic/theonlygrid-drive/releases/latest)
- **Politika privatnosti:** https://vahidzekic.github.io/theonlygrid-drive/privatnost.html

Ovaj repozitorijum sadrži samo javni sajt (GitHub Pages, koren grane `main`) i izdanja desktop aplikacije.
Izvorni kod je u glavnom repozitorijumu projekta. Napomene o sajtu su u [SAJT.md](SAJT.md).

TOG Drive je u alfa fazi i radi na testnoj mreži.
